Bingo 2 point grants

Signs point codes and gift links for Bingo 2. Everything happens in this file — no server, no network calls.

Do not publish this page. It can sign points. Keep it on your machine (open the file directly), never commit a key with it, and never upload it to the site. The build script keeps tools/ out of every ZIP.

1. Signing key

Grants are ECDSA P-256 / SHA-256 signatures. The key lives in this browser until you delete it; export a copy if you want a backup.

No signing key loaded.

Anyone holding the private half (or the exported file) can mint points.
Then that copy of Bingo 2 can redeem your gift links.

2. Mint grants

Role caps: promo 1,000 · operator 10,000 · prize 25,000 points per grant.

Up to 25 at a time.

3. Output

    4. Check a code

    Paste a grant code to confirm the signature, amount and expiry against the loaded public key.

    Format: GH2G.1.<role>.<payload>.<sig> — payload is base64url JSON {c,r,e,i,n} (points, role, expiry, issued, nonce), signed over the first four parts. Points are score tokens with no cash value; a grant is only worth what the game's verifier accepts.
